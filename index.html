Sphère 360 est une visionneuse gratuite de panoramas pour iPhone et iPad. A free panorama viewer for iPhone and iPad.

FrançaisEnglishContact

Premiers pas

  1. Importez un panorama avec Photos ou Fichiers. Vous pouvez aussi choisir « Essayer avec une démo » dans la bibliothèque vide.
  2. Ouvrez une vignette, puis glissez pour explorer. Un geste rapide prolonge la rotation ; touchez pour l’arrêter.
  3. Pincez pour passer en Small Planet ou en Tunnel. Le geste inverse revient vers la vue 360°.
  4. Touchez la photo pour masquer ou réafficher les commandes. Double-touchez pour recentrer.
  5. Dans Carte, retrouvez les positions GPS ou placez vos photos manuellement. Un appui long sur une vignette permet de renommer une photo.

Formats et dépannage

Utilisez des panoramas équirectangulaires déjà assemblés en JPEG, HEIC/HEIF, PNG ou TIFF décodables par iOS. Les fichiers INSP, RAW/DNG, vidéos et images non assemblées doivent être convertis avec le logiciel de votre caméra. Une image 2:1 peut nécessiter une confirmation. Les zones absentes d’un panorama partiel restent sombres.

La recherche est facultative et limitée aux photos autorisées dans iOS. Si elle est interrompue, utilisez Reprendre. Les cartes et les originaux stockés uniquement dans iCloud demandent une connexion. Supprimer une photo dans Sphère conserve l’original dans Photos ou Fichiers.

Getting started

The app interface is currently in French.

  1. Import a panorama using Photos or Fichiers (Files). In an empty library, “Essayer avec une démo” opens a built-in demo.
  2. Open a thumbnail and drag to explore. A quick swipe keeps the view spinning; tap to stop it.
  3. Pinch into Small Planet or Tunnel. Reverse the gesture to return toward the 360° view.
  4. Tap the photo to hide or show controls. Double-tap to reset the view.
  5. Use Carte (Map) for GPS pins or manual placement. Long-press a thumbnail to rename a photo.

Formats and troubleshooting

Use already-stitched equirectangular panoramas in JPEG, HEIC/HEIF, PNG or TIFF formats that iOS can decode. INSP, RAW/DNG, videos and unstitched images require conversion using your camera’s software. A 2:1 image may need confirmation. Missing areas of partial panoramas remain dark.

Scanning is optional and uses only the photos you allow in iOS. Use Reprendre (Resume) if a search stops. Maps and originals stored only in iCloud need an internet connection. Deleting a photo in Sphère preserves the original in Photos or Files.

Contacter l’assistance / Contact support

Pour une question ou un problème, ouvrez une demande d’assistance sur GitHub. Indiquez votre modèle d’appareil, la version d’iOS, la version de Sphère et les étapes pour reproduire le problème. Un compte GitHub est nécessaire. Les demandes sont publiques : ne joignez pas de photo personnelle, de coordonnées GPS ou d’information confidentielle.

For help, open a support request on GitHub. Include your device model, iOS version, Sphère version and steps to reproduce the issue. A GitHub account is required. Requests are public: do not include personal photos, GPS coordinates or confidential information.
